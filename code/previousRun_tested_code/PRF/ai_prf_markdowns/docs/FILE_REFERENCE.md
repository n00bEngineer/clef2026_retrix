## Java Source Files

### Core Implementation
```
Location: code/src/main/java/unipd/se/
```

#### PseudoRelevanceFeedback.java
- **Purpose**: Core PRF algorithm
- **Main Methods**:
  - `performPRF()` - Single-pass PRF expansion
  - `twoPassSearchWithPRF()` - Complete two-pass search
- **Key Class**: `PRFResult` - Container for results
- **Status**: Production ready

#### PRFExample.java
- **Purpose**: Single-query demonstration
- **Usage**: `java -cp target/classes unipd.se.PRFExample papers.json "query"`
- **Output**: `results/prf_demo_results.json`
- **Status**: Runnable example

#### PRFBatchExample.java
- **Purpose**: Batch query processing
- **Usage**: `java -cp target/classes unipd.se.PRFBatchExample papers.json queries.json`
- **Output**: `results/prf_batch_comparison.json`
- **Status**: Runnable example

#### PRFValidator.java
- **Purpose**: Testing and validation
- **Usage**: `java -cp target/classes unipd.se.PRFValidator`
- **Tests**: Parameter sensitivity, consistency, edge cases
- **Status**: Runnable tests

#### PRFConfig.java
- **Purpose**: Configuration presets and tuning
- **Classes**: 10 predefined `Config` objects
- **Usage**: `java -cp target/classes unipd.se.PRFConfig`
- **Status**: Configuration system ready

#### PRFIntegration.java
- **Purpose**: Integration examples for Main.java
- **Methods**: 4 integration patterns
  - `integrateSimplePRF()` - Replace BM25 with PRF
  - `hybridBM25andPRF()` - Combine BM25 + PRF
  - `adaptivePRF()` - Query-adaptive configuration
  - `parallelPRF()` - Parallel execution
- **Status**: Integration guide provided
